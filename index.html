// how it works — buyers

Your subscription first. The pool when it runs dry.

// principles

The boring rules that make this legitimate.

There's already a gray market for "cheap Claude tokens" — pooled accounts, stolen credentials, silently swapped models, prompts harvested and resold. Overflow is a diff against that:

gray_market.md → overflow.md
- pooled subscription accounts & shared logins
+ compute the seller actually owns, serving openly-licensed models
- silent model substitution ("Claude" that isn't)
+ every response stamped with the exact model that produced it
- prompts harvested and resold as training data
+ metered, not logged — your prompts are not a product
- accounts drained while owners sleep
+ hard token caps + instant revocation, enforced at the gateway
proprietary models join only via official partner channels.
